# douyin-demo · 抖音类短视频项目

这个文件夹是"抖音项目"的专属工作区。跟这个项目有关的代码、资料、问题和提问优化，都放在这里。

## 现在有什么

- `app/`：开源项目 [zyronon/douyin](https://github.com/zyronon/douyin) 编译后的**静态演示版**，是一个用 Vue 3 仿写的抖音网页端界面，包括刷视频、评论、消息、个人页等，数据由 Mock.js 模拟。
  - 只有构建产物，**没有源码**。要改功能就得拿到源码（见下文“如何拿源码”）。
  - 页面通过 `lib.baomitu.com` CDN 加载 Vue、vue-router、Mock.js，所以运行时需要联网。
- `docs/`：项目资料、提问记录、提问优化模板。

## 许可（重要）

- 原项目采用 **GPL-3.0** 协议，作者注明**不得用于商业用途**。
- 这个演示只能拿来学习。我的目标是做能赚钱的项目，所以如果要商用，必须自己重写，或者先取得原作者授权。不要把 `app/` 里的代码或素材直接拿去商用；遇到相关需求时要主动提醒我。

## 怎么运行

页面里的图片和数据用的是 `/images/...` 这种绝对路径，所以必须把 `app/` 当作网站根目录：

```bash
cd douyin-demo/app
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

直接双击 `index.html` 打不开（路径不对，而且浏览器会拦截本地文件请求）。

## 如何拿源码（需要改功能时）

```bash
cd douyin-demo
git clone --depth 1 https://github.com/zyronon/douyin src
```

源码默认不提交（已写进 `.gitignore`）。安装和启动步骤以源码仓库自己的 README 为准，先读它再动手。

## 提问优化（每次都做）

我的问题有时说得比较随意。遇到含糊的需求时：

1. 先把问题改写成一条清楚的任务，包括：目标 / 背景 / 约束 / 期望的输出，用一两行写给我看。
2. 如果有关键的东西拿不准，只问一个最关键的问题；能合理假设的就直接假设，并写明假设了什么。
3. 然后直接动手做。

每个值得留档的问题，都在 `docs/提问记录.md` 末尾追加一条：原始提问 → 优化后的提问 → 结论或产出。
